# Red-Green-Refactor

Source: `test-driven-development`.

1. Écrire un test minimal qui décrit le comportement attendu.
2. Exécuter ce test et confirmer qu’il échoue pour l’absence du comportement.
3. Implémenter le minimum nécessaire.
4. Réexécuter le test ciblé, puis la suite pertinente.
5. Refactoriser uniquement lorsque tout est vert.
